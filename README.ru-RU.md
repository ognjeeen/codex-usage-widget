# Виджет лимитов Codex для Windows

[English](README.md) · [简体中文](README.zh-CN.md)

Виджет показывает остаток лимитов подписки Codex и время их сброса на рабочем столе или рядом с областью уведомлений. Он получает данные через локальный сервер приложений Codex CLI. Это независимая утилита.

## Запуск

1. Распакуйте архив и запустите `CodexUsageWidget.exe`. Сборка включает среду .NET.
2. Проверьте, что команда `codex --version` работает в PowerShell и выполнен вход в Codex CLI.
3. Откройте **Настройки → Язык → Русский**. Режим **Как в Windows** тоже выбирает русский, если это язык интерфейса Windows.

Требуется Windows 10 версии 1809 или новее. Если Codex CLI установлен вне `PATH`, задайте полный путь к `codex.cmd` или `codex.exe` в переменной `CODEX_USAGE_WIDGET_CODEX_PATH`.

## Управление

- Нажмите `−`, чтобы перенести виджет на панель задач. Для возврата на рабочий стол нажмите правой кнопкой на индикатор и выберите **Перенести на рабочий стол**.
- В **Настройках** можно выбрать лимит для индикатора, формат времени, тему, акцентный цвет, подробный или компактный вид и запуск вместе с Windows.
- Данные обновляются каждые две минуты и при уведомлениях Codex. В контекстном меню есть команда **Обновить**.
- Подробный вид также показывает доступные кредиты, сбросы, статистику токенов и лимиты отдельных моделей, если их возвращает Codex. Использование сброса требует подтверждения.
- В разделе **Активность Codex** можно настроить обработчики, чтобы точки на индикаторе двигались, пока выполняется задача. Виджет показывает изменения в `hooks.json` до их записи. Разрешение обработчиков выдаётся в Codex через `/hooks`.

## Данные и удаление

Настройки и диагностические журналы хранятся в `%LOCALAPPDATA%\CodexUsageWidget`. Для удаления завершите работу виджета, предварительно отключив автозапуск в настройках и удалив обработчики активности, если вы их устанавливали. Затем удалите папку приложения и, если настройки больше не нужны, папку с локальными данными.
